    Install Local Yep.

    A Claude Code add-on that gives your agent memory surviving between sessions, kept in a SQLite file on your own machine. You need Python 3.10+ and Claude Code installed.

    §1 install

    Windows · PowerShell

    iwr https://yepgent.com/dl/install.ps1 -OutFile install.ps1
./install.ps1 -Gated

    macOS · Linux

    curl -fsSL https://yepgent.com/dl/install.sh -o install.sh
bash install.sh --gated

    The script checks your prerequisites, installs Local Yep with pipx, and asks for your activation token. Then open a new terminal and run gent in any folder. If you skipped the token, yepgent license activate <token> works later.

    Local Yep runs on your Claude Code subscription or API key and never touches those credentials. Installing means accepting the alpha Terms.
